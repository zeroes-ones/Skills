## Related reading in this library

- `agent-eval-pipeline` — the judge rubrics, calibration discipline, and statistical gates this
  skill's independence requirements feed into
- `doubt-driven-development` — the adversarial fresh-context review variant, as a practice on code
- `verification-before-completion` — confirming an individual change is actually done
- `multi-agent-orchestration` — the topologies (Debate, Evaluator-Optimizer) that give the verifier a
  role to occupy
- `workflow-graph-authoring` — expressing producer/verifier splits, gates and `exit_when` in a
  manifest so independence is structural rather than promised
- `agent-handoff-protocol` — building the verifier's payload so reasoning is excluded by construction
- `product-analyst` — designing and reading the business metric a target stands for
- `observability-engineer` — instrumenting rejection rate per artifact class and paired harm metrics
- `cost-accounting` — costing verification against the re-work it prevents (cost per successful run,
  not cost per call)
- `code-reviewer` — the code-level reviewer whose independence properties this skill generalises
