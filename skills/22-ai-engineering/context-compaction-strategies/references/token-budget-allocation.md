# Token Budget Allocation Framework

## Default Budget Template (4,500 tokens)

| Section | Allocation | Tokens | Rationale |
|---------|-----------|--------|-----------|
| Frontmatter | 5% | 225 | Metadata, routing, compatibility |
| Ground Rules | 15% | 675 | Highest impact on agent behavior |
| Expert Mindset | 5% | 225 | Cognitive framing |
| Operating Levels | 5% | 225 | Strategic context |
| When to Use | 3% | 135 | Negative triggers |
| Core Workflow | 10% | 450 | Process template |
| Decision Trees | 25% | 1,125 | Primary decision support |
| Cross-Skill | 5% | 225 | Integration context |
| Proactive Triggers | 3% | 135 | Automation hooks |
| What Good Looks Like | 5% | 225 | Examples and anti-patterns |
| Deliberate Practice | 3% | 135 | Human training |
| Gotchas | 8% | 360 | Failure mode catalog |
| Anti-Rationalization | 3% | 135 | Hard constraints |
| Verification | 3% | 135 | Quality checklist |
| References | 2% | 90 | Pointer summaries |

## Budget Optimization Rules
1. **Ground Rules always get full allocation** — constraints are non-negotiable
2. **Decision trees scale with complexity** — 5-7 trees at 150-200 tokens each
3. **Gotchas merit their allocation** — dollar-quantified failures prevent real losses
4. **Examples can be pruned first** — they illustrate, not define
