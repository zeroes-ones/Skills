# Personal Ethics Design — portability: personal, coaching, small team

<!-- QUICK: 30s --> A tactical guide to design and operate a personal ethics system: clarifying values, real-time decision tools, stakeholder mapping, and a whistleblowing decision framework.

## RESEARCH_PREREQUISITE

| RP | Description |
|----|-------------|
| RP1 | Current stated values or none |
| RP2 | Major decision types you face regularly |
| RP3 | Stakeholder list and power differentials |
| RP4 | Known conflict-of-interest situations |
| RP5 | Legal and professional constraints (note: seek counsel externally) |
| RP6 | Support network for accountability |
| RP7 | Risk tolerance for reputational loss |
| RP8 | Legacy goals and long-horizon priorities |

| Loop | Activity | Output |

## Quickstart (30s outputs)

1) Write your top 3 values as short phrases.
2) Run the front-page test on one recent decision: would you publish this choice on the front page? Yes/No.
3) If No, write one small change to make it pass or document why you cannot comply.

<!-- STANDARD: 3min --> Ground Rules

- Mechanical triggers:
  - If a decision affects vulnerable stakeholders, escalate to step with external accountability.
  - If conflict-of-interest present, recuse or disclose immediately.
  - If personal reputational risk is high (>3x monthly income), consult accountability network.
- Negative constraints:
  - Do not substitute personal ethics for professional or legal obligations.
  - Do not disclose confidential information without proper authority.
  - Avoid paralyzing perfectionism; use default conservative action when in doubt.

## Decision Tree: Ethical decision framework

Start
├─ Is there a clear legal prohibition?
│  ├─ Yes -> Do not proceed; consult counsel
│  └─ No ->
├─ Is there a direct victim or vulnerable party?
│  ├─ Yes -> Apply precautionary principle; prioritize harm minimization
│  └─ No ->
├─ Can the action be transparently explained on the front page?
│  ├─ Yes -> Proceed with disclosure plan
│  └─ No -> Modify action to meet public-test or recuse
├─ Does the action create long-term dependency or moral licensing?
│  ├─ Yes -> Add sunset clause and monitoring
│  └─ No ->
└─ Use veil-of-ignorance simulation to check distributional effects

## Core Workflow

STANDARD: (10–30 minutes)
1. Identify ethical dimension: legal, harm, autonomy, fairness, loyalty.
2. Map affected stakeholders and power asymmetries.
3. Run three frameworks: front-page test, role-model test, veil-of-ignorance.
4. Choose action with mitigation and monitoring plan.

DEEP: (30–120 minutes)
1. Build stakeholder influence diagram and quantify probable harms.
2. Run consequentialist tally and deontological rule-check in parallel; reconcile differences.
3. Draft ethical will/legacy note describing reasoning for archival transparency.

<!-- DEEP: 10+min --> Whistleblowing decision framework

Protocol (if encountering gross misconduct)
1. Document evidence precisely (dates, witnesses, artifacts).
2. Map harms and likely cover-up behaviors.
3. Seek confidential advice from trusted counsel or ombudsperson.
4. If internal remediation fails and public harm is severe, follow structured escalation: internal -> regulator -> media (with legal counsel).

Failure narratives & edge cases

- Moral licensing blindspot: doing a single good act then allowing a harmful shortcut. Fix: require baseline thresholds and independent audit.
- Loyalty conflicts: family or close friends create bias. Fix: recuse and delegate decision or use veil-of-ignorance swap test.
- Unclear duties: use role-priority lists to order conflicting obligations.

Advanced protocol: Ethical Pre-Commitments
1. Write a public short ethics charter and publish it where stakeholders can see it.
2. Set automatic accountability check-ins and triggers for potential conflicts.
3. Use third-party escrow for funds or decisions where conflict is likely.

## Error Decoder

| Error / Pitfall | Root Cause | Fix | Lesson |
|-----------------|------------|-----|--------|
| Ethical fading | Repetition + normalization | Rotate decision reviewers and institute audits | Visibility reduces fading |
| Moral licensing | One-off good deeds | Set independent decision thresholds | Don’t let single acts excuse harms |
| Failure to disclose COI | Incentive misalignment | Mandatory disclosures and penalties | Disclosure prevents hidden harms |
| Paralysis by perfection | Fear of making wrong choice | Use conservative default rule and review | Action beats endless doubt |
| Whistleblowing harm | Poor documentation | Follow strict evidence protocol + counsel | Preparation reduces backlash |

## Best Practices

1. Write a 1-page personal ethics charter and update annually.
2. Use stakeholder mapping for any significant decision; list top 5 affected groups.
3. Always run front-page and role-model tests for high-impact actions.
4. Maintain an ethical decision journal with scenario, rule applied, and outcome.
5. Use veil-of-ignorance for distributional fairness checks.
6. Pre-commit publicly where conflicts are likely (financial disclosures, recusal clauses).
7. Employ third-party accountability for high-stakes decisions.
8. Document everything when suspecting wrongdoing; follow secure evidence practices.
9. Schedule semi-annual ethics reviews with an accountability partner.
10. Add sunset clauses to long-term deals that can create dependence.

## Exercises (5–15 minutes)

Exercise 1: Values prioritization (10 min)
1. List 10 candidate values.
2. Reduce to top 5 via pairwise comparison.
3. For each top value, write a 1-line behavioral rule.

Exercise 2: Front-page test drill (5 min)
1. Pick a recent discretionary choice.
2. Imagine front-page headline; write the headline and one tweak to make it publishable.

## Verification: measure progress

- Count of decisions passing front-page test over 90 days.
- Number of disclosed COIs vs undisclosed discovered; target full disclosure.
- Whistleblowing readiness: presence of documented evidence sets when needed.
- Ethics charter adoption: percent of major decisions referenced against charter.

## What Good Looks Like

- Transparent decision logs correlated with low ethical incidents.
- Quick, defensible responses to front-page test queries.
- Clear recusal where conflicts exist and documented mitigation plans.
- Whistleblowing decisions that follow evidence-based protocol and minimize harm.
