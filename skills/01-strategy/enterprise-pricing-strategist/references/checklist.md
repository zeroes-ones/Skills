# Enterprise Deal Verification Checklist

## Pre-Proposal Gate

- [ ] Customer value quantified (ROI model with customer-specific inputs)
- [ ] Champion identified (name, title, internal selling capability)
- [ ] Budget confirmed (verbal or written, not assumed)
- [ ] Competitor landscape mapped (who else is in the deal? position?)
- [ ] Compliance requirements gathered (SOC 2, ISO, HIPAA, FedRAMP?)
- [ ] Procurement timeline understood (when does budget need to be spent?)
- [ ] Decision-makers mapped (champion + economic buyer + technical evaluator + procurement)
- [ ] Price anchor set (value-based, not cost-plus)

## Pre-Approval Gate

- [ ] Discount within AE authority? If not, approval matrix triggered
- [ ] Business case documented (volume commitment, strategic value, competitive pressure)
- [ ] ACV above floor ($25K-$50K minimum)?
- [ ] Payment terms standard (annual upfront, Net-30)?
- [ ] Multi-year escalator built in (5-7% annual)?
- [ ] No MFN clause in contract language?
- [ ] Liability cap confirmed (12-24 months fees)?

## Pre-Close Gate

- [ ] Legal review complete (MSA, DPA, SLA all reviewed)
- [ ] Security review complete (SOC 2 shared, pen test summary provided)
- [ ] Insurance certificates current and shared with customer
- [ ] Data processing agreement executed (if GDPR applies)
- [ ] Deal desk approval chain documented in CPQ
- [ ] Pricing committee approval documented (if applicable)
- [ ] Quote matches approved configuration (no drift)

## Post-Close Gate

- [ ] Contract filed in document management system
- [ ] Billing system configured (correct price, term, payment schedule)
- [ ] CSM assigned and introduced within 48 hours
- [ ] QBR cadence scheduled (first QBR within 90 days)
- [ ] Onboarding kickoff scheduled within 1 week of close
- [ ] Champion sent thank-you + executive sponsor introduction
- [ ] Win/loss analysis logged (why we won — for future reference)

## Quarterly Health Check

- [ ] All enterprise accounts have had QBR in last 90 days
- [ ] Value delivered quantified and shared with customer stakeholders
- [ ] Product usage trending up or stable (not declining)
- [ ] Champion still in role? If not, who's the new champion?
- [ ] Expansion opportunity identified (more seats, new products, new departments)?
- [ ] Renewal at risk? (check health score, support tickets, NPS)
- [ ] Competitive threat detected? (competitor engaging with customer)
- [ ] Price review: is this account still at market-appropriate pricing?

## Annual Audit

- [ ] SOC 2 Type II renewed and current
- [ ] Penetration test completed and summary available
- [ ] Insurance policies renewed, certificates current
- [ ] DPA and SCCs reviewed (any regulatory changes?)
- [ ] Approval matrix reviewed (still appropriate for current deal sizes?)
- [ ] Discount analysis: average discount rate, outliers, coaching opportunities
- [ ] MFN audit: any active MFN clauses? Are they scoped appropriately?
- [ ] Enterprise tier competitiveness reviewed (mystery shop competitors)
