# Universal Message Envelope — Complete JSON Schema

## Schema Definition

```json
{
  "$schema": "https://skills-repo/cross-skill-message/v1",
  "envelope": {
    "message_id": "uuid",
    "correlation_id": "uuid | null",
    "source_skill": "string",
    "target_skill": "string | *",
    "pattern": "request | response | event | handoff | feedback | conflict_resolution | orchestration_command",
    "schema_version": "semver",
    "timestamp": "ISO8601",
    "expires_at": "ISO8601 | null",
    "priority": "low | normal | high | critical",
    "idempotency_key": "uuid | null"
  },
  "payload": {},
  "quality": {
    "confidence": "float 0.0-1.0",
    "data_freshness": "ISO8601 | null",
    "calibration_version": "semver | null"
  },
  "trace": {
    "parent_message_id": "uuid | null",
    "skill_chain": ["string"],
    "processing_time_ms": "integer"
  }
}

```

## Field Specification

| Field | Required | Type | Description |
|-------|----------|------|-------------|
| message_id | YES | UUID v4 | Globally unique. Generated by sender. Never reused. |
| correlation_id | NO | UUID | Links request→response, event→reaction. Same correlation_id means "these messages are about the same thing." |
| source_skill | YES | string | Exact skill name from YAML frontmatter `name` field. Case-sensitive. |
| target_skill | YES | string or "*" | Exact skill name or "*" for broadcast pub-sub. Case-sensitive. |
| pattern | YES | enum | Which of the 6 communication patterns this message uses |
| schema_version | YES | semver | Version of `payload` schema. Follows semver MAJOR.MINOR.PATCH |
| timestamp | YES | ISO8601 | When message was created. UTC. Millisecond precision. |
| expires_at | NO | ISO8601 | After this time, message is stale and receivers MUST reject |
| priority | YES | enum | Processing priority. Critical = circuit breaker bypass (use sparingly) |
| idempotency_key | NO | UUID | For Request-Response retry safety. Same key = same logical request |

## Validation Rules

1. message_id must be unique across all messages in a session
2. source_skill must match a registered skill name
3. pattern must be one of the 7 enum values
4. schema_version must be valid semver
5. timestamp must be in the past (not future-dated)
6. If expires_at is set, it must be after timestamp
7. skill_chain must not contain duplicates (no cycles)

## Pattern-Specific Payload Schemas

### Request-Response

```json
{
  "payload": {
    "request_type": "string",
    "parameters": {},
    "response_expected_by": "ISO8601"
  }
}

```

### Publish-Subscribe (Event)

```json
{
  "payload": {
    "event_type": "string from event taxonomy",
    "event_data": {},
    "event_source": "string (original source, may differ from envelope source_skill)"
  }
}

```

### Handoff

```json
{
  "payload": {
    "transferred_state": {},
    "excluded_state": ["field_names_not_transferred"],
    "resume_point": "string (phase or step identifier)",
    "validation_hash": "sha256"
  }
}

```

### Feedback

```json
{
  "payload": {
    "reference_output_id": "uuid (message_id of output being evaluated)",
    "quality_score": "float 0.0-1.0",
    "issues": [{"type": "string", "severity": "low|medium|high|critical", "detail": "string"}],
    "producer_action_required": "string",
    "producer_action_deadline": "ISO8601"
  }
}

```
