# ISO 27001/27002 — Information Security Controls for Data

## Overview
ISO/IEC 27001:2022 specifies requirements for an Information Security Management System (ISMS). ISO/IEC 27002:2022 provides implementation guidance for controls.

## Data Security-Relevant Controls (2022 Edition)

### A.5.10 — Information Classification
- Classify data based on confidentiality, integrity, availability
- Consistent labeling across organization
- Classification drives protection level

### A.8.24 — Use of Cryptography
- Cryptographic policy for data at rest and transit
- Key management lifecycle (generation, distribution, rotation, destruction)
- Algorithm selection based on standards

### A.8.10 — Information Deletion
- Secure deletion per classification level
- Verify deletion completeness
- Maintain deletion audit trail

### A.8.12 — Data Leakage Prevention
- DLP for network, endpoint, and cloud
- Data exfiltration monitoring
- Block sensitive data transfers

## Annex A Controls
- 93 controls in 4 categories: Organizational, People, Physical, Technological
- Mandatory documentation: SoA (Statement of Applicability)
