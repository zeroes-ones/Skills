# NIST SP 800-122 — Protecting PII Confidentiality

## Overview
NIST SP 800-122 provides guidance for protecting Personally Identifiable Information (PII) confidentiality throughout the information lifecycle.

## PII Identification
- **Linked PII**: Direct identifiers (name, SSN, biometrics, email)
- **Linkable PII**: Indirect identifiers that can identify when combined (DOB, ZIP, gender, occupation)
- **Unlinkeable PII**: Cannot be used to identify individual (aggregate statistics)

## Protection Framework
1. **Identify PII**: Data inventory with PII categorization
2. **Minimize**: Collect only what is operationally necessary
3. **De-identify**: Anonymization or pseudonymization where possible
4. **Protect**: Encryption at rest and transit, access controls, audit logging
5. **Govern**: Retention limits, secure disposal, breach response

## Key Controls
- Encryption: AES-256 at rest, TLS 1.3 in transit
- Access: Least privilege, just-in-time, break-glass
- Audit: All PII access logged to immutable store
- Disposal: NIST SP 800-88 Purge or Destroy level
