# IBM Guardium — Database Activity Monitoring

## Overview
IBM Security Guardium provides data activity monitoring, vulnerability assessment, and data protection for heterogeneous database environments.

## Core Capabilities

### Database Activity Monitoring
- Real-time policy-based monitoring
- Granular audit trail per SQL statement
- Privileged user monitoring (DBA activity)
- Session-level forensic data

### Vulnerability Assessment
- 5,000+ pre-built tests (STIG, CIS, CVE)
- Database configuration assessment
- Entitlement reporting (who has access to what)
- Risk scoring and compliance reports

### Data Discovery & Classification
- Automated sensitive data discovery
- Classification based on patterns (PII, PHI, PCI, IP)
- Data-at-rest scanning

### Compliance Automation
- Pre-built reports for PCI DSS, HIPAA, SOX, GDPR, ISO 27001
- Automated compliance workflows
- Sign-off and attestation

## Architecture
- **Collector**: Lightweight agent, no performance impact
- **Aggregator**: Centralized reporting and policy management
- **S-TAP**: Software Tap for network-based monitoring
