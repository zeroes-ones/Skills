# CCPA/CPRA — California Data Security Requirements

## Overview
California Consumer Privacy Act (CCPA) as amended by the California Privacy Rights Act (CPRA) establishes data protections for California residents.

## Data Security Obligations
- **Reasonable security**: Implement and maintain reasonable security procedures and practices
- **Data minimization**: Collect, use, retain only what is reasonably necessary and proportionate
- **Purpose limitation**: Cannot use data for incompatible purposes without notice
- **Storage limitation**: Cannot retain data longer than reasonably necessary

## Consumer Rights Impacting Data Security
- **Right to Know**: Requires comprehensive data inventory
- **Right to Delete**: Technical deletion cascade across all systems
- **Right to Correct**: Data quality and accuracy mechanisms
- **Right to Limit Use of Sensitive PI**: Granular access controls

## Sensitive Personal Information
- SSN, driver's license, passport
- Account credentials + password
- Precise geolocation
- Racial/ethnic origin, religious beliefs
- Genetic data, biometric data
- Health information, sex life/orientation

## Private Right of Action
- Statutory damages: $100-$750 per consumer per incident
- Applies to data breaches resulting from failure to implement reasonable security
