# Imperva — Database Security Solutions

## Overview
Imperva provides database activity monitoring, vulnerability assessment, and protection for on-premises and cloud databases.

## Core Capabilities

### Database Activity Monitoring (DAM)
- Real-time SQL traffic monitoring
- Policy-based alerting (privileged user, sensitive table access)
- Session-level auditing (who did what, when, from where)
- Separation of duties between DBAs and security

### Vulnerability Assessment
- Automated discovery of database instances
- CIS Benchmark-based assessment
- Configuration drift detection
- Risk scoring and prioritization

### Data Protection
- Data masking for non-production (static + dynamic)
- Sensitive data discovery with classification
- User rights management (excess privilege identification)

### Database Firewall
- SQL injection prevention
- Virtual patching for known vulnerabilities
- Protocol-level inspection

## Supported Databases
- Oracle, SQL Server, MySQL, PostgreSQL, MongoDB, Cassandra, DB2, SAP HANA, Big Data
