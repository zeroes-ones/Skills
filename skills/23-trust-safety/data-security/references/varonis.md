# Varonis — Data Security Platform

## Overview
Varonis provides a comprehensive data security platform for discovering, classifying, and protecting sensitive data across on-premises and cloud environments.

## Core Capabilities

### Data Classification
- Behavioral-based classification (not just regex)
- Sensitive data discovery across NAS, SharePoint, Exchange, cloud
- Automatic classification policy for PII, PHI, PCI, IP

### Threat Detection
- User behavior analytics (UEBA) for data access
- Ransomware detection (mass encryption patterns)
- Insider threat detection (unusual data access, exfiltration)

### Data Activity Monitoring
- Real-time audit trail of all data access
- Privilege analysis (who can access what)
- Stale data identification (excess permissions)

### Data Protection
- Automated remediation (remove global access, quarantine)
- Data ownership identification
- Retention and disposal recommendations

## Deployment
- On-premises: Windows file servers, NAS, SharePoint
- Cloud: Box, Salesforce, Microsoft 365, Google Workspace
- Hybrid: Unified view across environments
