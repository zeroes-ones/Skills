# Azure Purview — Unified Data Governance

## Overview
Microsoft Purview provides unified data governance, classification, and cataloging across multi-cloud and on-premises data estates.

## Data Map
- **Automated scanning**: 100+ data sources (Azure, AWS, GCP, on-premises)
- **Lineage**: Automatic data lineage from ingestion to consumption
- **Schema extraction**: Automatic schema classification and tagging

## Classification
- **System classifications**: 200+ built-in (credit card, SSN, email, IP address)
- **Custom classifications**: Regex + dictionary-based
- **Auto-classification**: ML-based column-level classification
- **Microsoft Information Protection integration**: Uses MIP sensitivity labels

## Key Capabilities
- **Business glossary**: Standardized business terminology
- **Data lineage**: End-to-end visualization (ADF, Synapse, Databricks, Power BI)
- **Insights**: Data estate health, classification coverage, compliance gaps
- **Policy enforcement**: Access policies based on classification

## Compliance Features
- **GDPR/CCPA asset grouping**: Group data assets by regulation
- **Sensitive data reports**: Classification distribution across data estate
- **Data owner assignment**: Stewardship and accountability
