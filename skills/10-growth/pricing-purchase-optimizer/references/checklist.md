# Pricing Page Verification Checklist

## Pre-Launch Gate

- [ ] Value proposition visible above fold before any price
- [ ] 2-4 tiers (excluding Enterprise) with middle tier visually emphasized
- [ ] Annual toggle present, defaulted to annual, savings percentage shown
- [ ] Feature comparison table: checkmarks/Xs, grayscale for unavailable
- [ ] CTA copy action-oriented ("Start Free Trial" vs "Submit")
- [ ] Social proof near CTAs (logos, testimonials, G2 rating)
- [ ] Mobile: vertical stack, sticky CTA, 44px+ tap targets, no horizontal scroll
- [ ] Total cost (incl. tax/VAT) shown before payment details step
- [ ] No dark patterns (forced continuity, hidden fees, pre-checked add-ons)
- [ ] Abandoned cart recovery email sequence configured

## Post-Launch Gate

- [ ] Funnel analytics instrumented (page view → tier click → signup → payment)
- [ ] Session recording active (Hotjar, FullStory, Clarity)
- [ ] Baseline conversion metrics documented (first 7 days)
- [ ] A/B testing tool integrated and test backlog prioritized
- [ ] Revenue attribution by variant operational

## Before A/B Test

- [ ] Single variable being tested (tier count OR CTA copy OR toggle default, not all)
- [ ] Hypothesis documented: "Changing X from A to B will increase Y by Z%"
- [ ] Primary metric defined: conversion rate, ARPU, or RPV
- [ ] MDE calculated: minimum detectable effect size
- [ ] Sample size requirement calculated: 10K+ per variant
- [ ] Duration set: minimum 2 weeks
- [ ] RAMP plan documented: 5% → 25% → 50% → 100%
- [ ] Guardrail metrics defined: RPV, refund rate, support tickets

## Post-Test Gate

- [ ] p < 0.05 on primary metric
- [ ] Effect size > MDE (practical significance, not just statistical)
- [ ] Segment analysis: no segment where variant underperformed by >10%
- [ ] RPV not degraded (conversion win isn't LTV loss)
- [ ] Findings documented in knowledge base for future tests
- [ ] Winner deployed at 100% with 48hr monitoring period

## Quarterly Audit

- [ ] Competitor pricing pages re-benchmarked (any changes?)
- [ ] Mobile conversion rate > 50% of desktop conversion
- [ ] Checkout abandonment rate < 60%
- [ ] Annual plan selection > 40% of new customers
- [ ] Dark pattern audit: zero deceptive patterns found
- [ ] International localization current for top 3 markets
- [ ] A/B test cadence: at least 1 pricing test running per quarter
