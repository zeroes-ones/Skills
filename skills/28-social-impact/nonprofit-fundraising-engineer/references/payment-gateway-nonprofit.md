# Payment Gateway Configuration for Nonprofits
> Reference: Nonprofit pricing, fee comparison, enrollment process

## Fee Comparison (US)

| Processor | Standard Rate | Nonprofit Rate | Annual Savings on $1M |
|-----------|-------------|----------------|----------------------|
| Stripe | 2.9% + 30¢ | 2.2% + 30¢ | ~$7,000 |
| PayPal | 2.89% + 49¢ | 1.99% + 49¢ (Giving Fund) | ~$9,000 |
| Braintree | 2.9% + 30¢ | Contact sales | Varies |

## Enrollment

### Stripe Nonprofit Discount
1. Create Stripe account with organization details
2. Submit 501(c)(3) determination letter via support
3. Processing time: 1-2 weeks
4. Discount applies to future charges only (not retroactive)

### PayPal Giving Fund
1. Enroll organization at paypal.com/givingfund
2. Requires: EIN, bank account, org details
3. Donors can give via PayPal Giving Fund with 0% fee (donor covers processing)

## Multi-Currency
- Stripe: 135+ currencies, +1% conversion fee
- PayPal: 25 currencies, built-in conversion
- Braintree: 130+ currencies via Adyen integration

## ACH/Bank Transfer
- Stripe ACH: 0.8% (cap $5)
- For donations >$1,000, ACH saves significant fees
- Offer ACH option for major gifts
