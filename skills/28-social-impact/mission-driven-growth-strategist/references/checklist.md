# Mission-Driven Growth Strategist — Per-Phase Verification Checklist

## Phase 1: Theory of Change Design

- [ ] Long-term impact statement defined: specific population, specific outcome, measurable level, timeframe
- [ ] Backward mapping complete: Impact → Outcomes → Outputs → Activities
- [ ] All necessary preconditions identified (what MUST be true for each outcome)
- [ ] Assumptions named for every arrow in the ToC
- [ ] Each assumption rated: Strong / Moderate / Weak / Unknown
- [ ] Weak and Unknown assumptions prioritized for testing
- [ ] At least 5 outcome indicators defined
- [ ] Indicators mapped to IRIS+ codes or SDG targets where applicable
- [ ] Data collection methodology documented for each indicator
- [ ] Data collection frequency and responsibility assigned
- [ ] Baseline data collected OR baseline collection plan documented with timeline
- [ ] Assumption testing plan documented: method, sample size, timeline, budget
- [ ] Outcome owners assigned (named individuals accountable for each outcome)
- [ ] Quarterly ToC review cadence established
- [ ] Beneficiary input incorporated into indicator selection

## Phase 2: Legal Structure & Entity Design

- [ ] Jurisdiction confirmed (country, state/province)
- [ ] Available entity types in jurisdiction mapped
- [ ] Mission lock requirement rated (1-5) based on acquisition risk, founder succession, and capital plans
- [ ] Entity type selected with rationale
- [ ] Enabling legislation cited (statute name, year, key provisions)
- [ ] Legal accountability mechanism documented:
  - [ ] For benefit corporation: public benefit purpose provision drafted
  - [ ] For B Corp: legal accountability amendment drafted
  - [ ] For CIC: community interest statement + asset lock drafted
  - [ ] For cooperative: bylaws with governance provisions drafted
  - [ ] For steward-ownership: golden share provisions drafted
- [ ] Governance rights mapped to stakeholder groups
- [ ] Board composition designed (seats, selection method, terms)
- [ ] Conversion/formation plan documented (timeline, filings, legal counsel engaged)
- [ ] Annual reporting obligations identified
- [ ] Estimated legal costs budgeted ($5K-$50K depending on complexity)
- [ ] Legal counsel qualified in this jurisdiction and entity type engaged or identified

## Phase 3: Impact Measurement Architecture

- [ ] Primary framework(s) selected (IRIS+, SDG, BIA, SROI, GRI, SASB)
- [ ] 5-10 core indicators defined with framework codes
- [ ] Both depth and breadth metrics included
- [ ] Data collection system designed:
  - [ ] Collection method (survey, admin data, observation, sensor)
  - [ ] Frequency (continuous, quarterly, annually)
  - [ ] Verification (third-party audit, internal QA, beneficiary validation)
- [ ] Measurement budget allocated (3-7% of program costs)
- [ ] Baseline established OR collection plan documented
- [ ] Annual targets set for each indicator (SMART criteria)
- [ ] Dashboard design complete with per-stakeholder views:
  - [ ] Board dashboard (quarterly)
  - [ ] Investor dashboard (IRIS+ aligned)
  - [ ] Fundraising dashboard (pipeline)
  - [ ] Beneficiary feedback dashboard
- [ ] Reporting cadence defined per stakeholder
- [ ] Data privacy and beneficiary consent protocols documented
- [ ] Technology/tools selected for data collection and analysis

## Phase 4: Sustainable Funding Strategy

- [ ] Revenue model assessed for mission alignment (scored 1-5)
- [ ] Revenue diversification plan with 3-5 year targets:
  - [ ] Year 1: Grant dependency ___%, Earned revenue ___%
  - [ ] Year 3: Grant dependency ___%, Earned revenue ___%
  - [ ] Year 5: Grant dependency ___%, Earned revenue ___%
- [ ] Capital stack designed with waterfall documented
- [ ] Return expectations by tranche defined
- [ ] Governance rights by tranche defined
- [ ] Exit mechanics for each investor class defined
- [ ] Alternative instruments evaluated (SIB, DPO, RBF, community bonds)
- [ ] 3-year financial sustainability model built with scenarios
- [ ] Funding acceptance criteria documented
- [ ] Concentration risk thresholds set and monitoring plan established
- [ ] Grant pipeline and impact investment pipeline documented
- [ ] Earned revenue pathway defined with timeline and investment required

## Phase 5: Stakeholder Governance Design

- [ ] Stakeholder map complete — all groups identified
- [ ] Power/Legitimacy/Urgency ratings completed for each group
- [ ] Board composition designed with seat allocations
- [ ] Beneficiary representation mechanism selected:
  - [ ] Voting board seat(s)
  - [ ] Community advisory council
  - [ ] Both
- [ ] Beneficiary governance capacity building plan:
  - [ ] Board orientation (in primary language)
  - [ ] Financial literacy training
  - [ ] Meeting stipends and accommodations
- [ ] Golden share or equivalent mission-lock mechanism designed
- [ ] Protected decisions defined (what requires golden share approval)
- [ ] Decision rights matrix documented for all critical decisions
- [ ] Community advisory council charter drafted (if applicable)
- [ ] Governance review cadence established (annual governance audit)
- [ ] Succession plan for golden share holder (if applicable)

## Cross-Cutting Verification

Before finalizing any mission-driven strategy, verify:

- [ ] All assumptions rated — no "obvious" assumptions left unexamined
- [ ] At least one beneficiary voice check: "Would the people we serve agree with this strategy?"
- [ ] Mission fidelity triggers set: automatic review when fidelity metrics breach thresholds
- [ ] Legal review completed or identified: jurisdiction-qualified counsel reviewed entity structure
- [ ] Financial model stress-tested: what if grant dependency doesn't decrease? what if largest funder exits?
- [ ] Scale gates defined: specific, measurable criteria that must be met before each growth phase
- [ ] Exit plan documented: what happens to the mission if the founder leaves, if acquired, if funding changes
- [ ] All "Complete when" statements from Core Workflow satisfied
