# Central Bank Reaction Functions

## Taylor Rule (Standard)
```
i = r* + π + 0.5(π - π*) + 0.5(y - y*)
```
Where:
- i = nominal policy rate
- r* = neutral real rate (r-star) ~0.5-1.5%
- π = current inflation (core PCE preferred)
- π* = inflation target (2%)
- y - y* = output gap

## Taylor Rule Variants
| Variant | Formula | Use Case |
|---------|---------|----------|
| Original (1993) | i = 2 + π + 0.5(π-2) + 0.5(y-y*) | GDP deflator, output gap |
| Fed's Balanced Approach | Same as standard but output gap weight doubled in ZLB | Post-GFC era |
| Bernanke Rule | i = r* + π + 1.0(π-π*) + 0.5(y-y*) | Inflation weight doubled |
| Yellen Rule | i = r* + π + 0.5(π-π*) + 1.0(y-y*) | Employment weight doubled (core PCE) |

## FOMC Communication Analysis
| Language | Hawkish/Dovish | Confidence |
|----------|---------------|------------|
| "Some participants" | Weak signal | 2-3 members |
| "Many participants" | Moderate signal | 5-8 members |
| "Most participants" | Strong signal | 9-14 members |
| "Almost all participants" | Consensus | 15+ members |
| "The Committee expects" | Forward guidance | FOMC consensus (not just participants) |

## ECB Specifics
- **Governing Council**: 26 members (6 Executive Board + 20 national governors)
- **Rotating votes**: Since July 2022, voting rights rotate among national governors
- **Hawk/Dove spectrum by nationality**: Northern countries (Germany, Netherlands, Austria) typically hawkish; Southern (Italy, Spain, Portugal) typically dovish
- **TPI (Transmission Protection Instrument)**: Unlimited bond purchases to prevent fragmentation

## BOJ Specifics
- **YCC (Yield Curve Control)**: 10Y JGB target ±0.5% (widened from ±0.25% in Dec 2022)
- **ETF purchases**: ¥12T annual ceiling (effectively abandoned in 2024)
- **Exit conditions**: Sustainable 2% inflation + wage growth + demand-pull (not cost-push) inflation

## PBoC Specifics
- **Multiple instruments**: RRR, MLF, LPR, PSL, relending facilities
- **Credit impulse as primary signal**: Change in flow of new credit / GDP
- **Currency management**: Daily CNY fix, counter-cyclical factor, reserve requirement on FX forwards
