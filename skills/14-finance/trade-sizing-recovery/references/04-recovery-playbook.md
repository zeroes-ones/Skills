# Recovery Playbook — Win Next

Companion to `SKILL.md` Decision Tree 3.

## The six steps after any loss

1. **Book it mentally the day it closes.** The dollars are gone; the lesson is the only asset left. Write the one-line lesson row.
2. **Reset size to base** (or half after two consecutive losses / any loss beyond −50%).
3. **Return to the proven class.** The recovery trade must come from the category with measured positive expectancy — never the category that just lost.
4. **Cooldown on the name.** 5 sessions, no re-entry, absent a brand-new gate-passed setup.
5. **Two wins at base → one ladder step.** Cap at 3 lots; step back to base after any loss. Streaks are for booking, not riding.
6. **Recompute the weekly table.** Recovery is complete when the active class's expectancy is green again — not when one trade "got it back".

## What recovery is NOT

- Not doubling size on the next idea ("it owes me").
- Not switching to a new, unproven class in frustration.
- Not holding a loser longer to avoid realizing the loss — the triage matrix already decided; the decision isn't renegotiated daily.
- Not "one trade to fix everything". Expectancy compounds; heroics decompose.

## Ladder state bookkeeping

| Event | Next order size |
|---|---|
| First order, new account/class | Base (1 lot) |
| 1 win in a row | Base |
| ≥2 wins in a row (same class only) | +1 lot, cap 3 |
| Any loss (1st) | Base |
| 2 consecutive losses OR any loss > −50% | Half size until one win |
| Win at half size | Back to base |

## Weekly expectancy review (20 min)

1. Pull closed trades from the ledger for the week.
2. Group by setup class; compute hit rate, avg win (R), avg loss (−R), expectancy (R).
3. Any class negative over ≥10 samples → halve or prune at the next review.
4. Update ladder state per account. Announce the state change before the next order idea.
