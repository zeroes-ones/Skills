# Tax-Aware Portfolio Management

## Wash Sale Rule

```

If you sell a security at a loss and buy the same or "substantially identical"
security within 30 days (before or after), the loss is disallowed for tax purposes.

Substantially identical: SPY and VOO = YES. SPY and QQQ = NO.

```

## Tax-Lot Selection

```

When selling partial position, select lots in this order:
1. Short-term losses (highest tax benefit)
2. Long-term losses
3. Long-term gains (lowest tax rate)
4. Short-term gains (highest tax rate — avoid if possible)

```

## Rebalancing Deferral

```

If >80% of needed sells are short-term gains:
  DEFER rebalancing until lots become long-term (>1 year held)
  Max deferral: 30 days
  If still short-term after 30 days: execute anyway, flag tax impact

```
