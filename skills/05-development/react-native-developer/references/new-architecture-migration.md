# New Architecture Migration — Fabric, TurboModules, JSI

> `[VERIFIED 2026-08]` against RN 0.76+ where the New Architecture is default. Verify the exact flag names against the installed RN version (RP1).

## What the New Architecture Is

| Piece | What it replaces | What changes |
|-------|------------------|--------------|
| **Fabric** | The old (Paper) renderer | New component lifecycle; `getDerivedStateFromProps`-era patterns behave differently; interop layer maps legacy components |
| **TurboModules** | Static, eager native modules | Lazy-loaded native modules with typed interfaces generated by **codegen** |
| **JSI** | The async bridge for JS↔native | Synchronous, direct JS↔C++/native calls; no serialization overhead |

## Enabling Flags

- Expo: `"newArchEnabled": true` in `app.json` (Expo SDK 53+ defaults it on).
- Bare: `newArchEnabled=true` in `android/gradle.properties` and the iOS Podfile install options.
- Codegen runs automatically at build; generate interfaces with `npx react-native codegen` when needed for debugging.

## Migration Plan (Deliberate, Not a Flag Flip)

1. **Audit libraries** — list every native dependency; check its New-Arch support (most major libs are compatible by RN 0.76).
2. **Enable the interop layer** for legacy modules — the interop layer maps Paper-style components and legacy modules during transition.
3. **Run codegen** and fix type errors in JS↔native calls.
4. **Test gestures and animations per screen** — Reanimated, gesture-handler, and camera/permission flows are the highest-regression areas.
5. **Flip `newArchEnabled`**, build both platforms, run the full E2E matrix.
6. **Monitor** interop warnings in the console; convert legacy modules incrementally.

## Known Regression Surfaces

- **Gesture handling** — simultaneous gestures, native-driver interactions.
- **Animated API** — JS-driven `Animated` on Fabric; prefer Reanimated worklets.
- **Imperative native calls** — `UIManager`-based calls need migration to the new API.
- **Custom Views** — Fabric requires the new component interface; use the interop layer until migrated.

## Rollback

Keep the legacy-bridge path viable for one release: if New Arch causes a production regression you can't fix in hours, disable the flag, ship, and re-migrate a screen at a time. Document the rollback in the release notes.
