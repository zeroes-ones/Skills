## Program Templates

### Needs Brief (one page)
| Field | Content |
|-------|---------|
| Business problem | Sales ramp is 6 months; target 3; cost of delay ~$40K/month/rep |
| Root cause | No structured 30/60/90; no real deals until month 3; no coaching cadence |
| Is training the fix? | Partially — knowledge gap exists, but pipeline tooling also blocks (routed to sales ops) |
| Target behavior change | Reps run discovery calls with the new framework and close their first deal by day 90 |
| Audience | 12 new AEs, 4 managers |
| Success measures | Ramp time 6→3 months; first-deal-by-day-90 rate; manager observation |

### 30/60/90 Onboarding Structure (per role)
| Window | Learn | Do | Deliver |
|--------|-------|----|---------|
| Day 1-30 | Company, product, role, tools | Shadowing, small scaffolded tasks | First real deliverable (small) |
| Day 31-60 | Deeper domain, advanced workflows | Independent work with review | Ramped milestone per role definition |
| Day 61-90 | Edge cases, cross-team work | Full ownership with coaching | Independent production output |

Support cast: buddy (day-to-day), manager (weekly check-in + feedback), mentor (domain/technical).

### Measurement Levels
| Level | Question | Method |
|-------|----------|--------|
| L1 Reaction | Did they like it? | Happy sheet (weak signal) |
| L2 Learning | Did they learn it? | Assessment / demonstration |
| L3 Behavior | Did they apply it? | Manager observation, work artifacts, 30-60 day check |
| L4 Results | Did it move the business? | Ramp time, error rate, retention, sales (honest attribution) |

## War Stories

- **The $150K program that changed nothing:** Sales leadership funded a large training program for a process gap. Reps already knew what to do; the CRM and lead routing blocked them. Post-program pipeline was flat, and the team felt talked-at. Lesson: diagnose root cause before designing — training over a broken system is waste and demoralizing.
- **The leadership program with no application:** 40 managers attended workshops; six months later no behavior change and the bench was still empty. The redesign added a real application project, coaching, and cohort accountability. Lesson: leadership develops through application and feedback, not attendance.
- **The 98% compliance completion:** Completion was 98%, yet an incident showed nobody internalized the policy. Regulators asked hard questions about the training's effectiveness. Fix: scenario-based assessment with consequences and a testable audit trail. Lesson: completion is not understanding; the audit trail is the product.
