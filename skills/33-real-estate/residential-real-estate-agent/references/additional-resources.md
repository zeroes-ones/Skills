## CMA Method — Selection Logic

### Comparable Selection Criteria
| Criterion | Rule of thumb |
|-----------|---------------|
| Property type | Same type (SFR, condo, townhouse) |
| Location | Same neighborhood/zip; expand radius only when comps are scarce |
| Size | Living area within ±20%; adjust $/sqft for differences |
| Beds/baths | Match or adjust; baths add more value per unit than beds in most markets |
| Condition | Match or adjust (updated vs dated); renovations can add 10-25% |
| Sale date | Within 6 months preferred; extend to 12-18 months for unique/luxury |
| Sale type | Prefer arm's-length sales; exclude distressed/related-party unless noted |

### Adjustment Notes
- Adjust, don't discard: present the logic for each adjustment in the CMA.
- Output a range (e.g., $820K-$860K) with the median and the reasoning — never a single rigged number.
- Show the overpricing cost table: at +10% over CMA, typical outcome is 30-60 extra days on market and a final price below the sharp initial list.

## Offer / Contract Checklists

### Before Writing an Offer
- [ ] Buyer pre-approval verified (or cash position confirmed)
- [ ] Property-specific CMA run on the subject home
- [ ] Contingency plan agreed: inspection / appraisal / financing
- [ ] Any waiver has a written risk discussion (signed)
- [ ] Closing-cost estimate provided
- [ ] Escalation cap (if escalation clause) documented and affordable

### Contract-to-Close Calendar (typical 30-45 days)
| Item | Timing | Owner |
|------|--------|-------|
| Purchase agreement + EMD | Day 0 | Agent / escrow |
| Disclosures delivered | Day 0-3 | Seller / agent |
| Inspection | Day 7-14 | Buyer + agent |
| Inspection resolution | Day 10-17 | Agent negotiates |
| Appraisal | Day 14-21 | Lender orders |
| Loan commitment | Day 21-30 | Lender |
| Final walkthrough | Day 30-44 | Buyer + agent |
| Closing / recording | Day 30-45 | Escrow / title |

## Disclosure & Compliance Notes

- Disclose ALL material facts in writing: known defects, past damage, HOA issues, zoning limits, deaths on property where required by state law.
- Agency relationships disclosed in writing per state law; informed consent for dual/designated agency.
- Fair housing: never steer, discriminate, or make assumptions about protected classes.
- The agent advises on process; contract language and legal disputes go to a real estate attorney (`legal-advisor`).

## War Stories

- **The 10% overprice:** Seller insisted on $899K against a CMA of $820-850K. The home sat 60 days, drew lowball offers, and finally closed at $805K — $45K below where a sharp initial price likely would have landed, plus 2 months of carrying costs. Lesson: the first two weeks set the price; overpricing costs more than pricing right on day one.
- **The waived inspection:** A buyer waived inspection "to win the bid" on the agent's casual advice. Foundation work cost $25K in year one. Lesson: every waiver needs a written risk discussion; when waiving is justified, a pre-offer inspection protects everyone.
- **The missed deadline:** A transaction lost $15K of earnest money because nobody tracked the financing contingency date — everyone assumed someone else was watching. Lesson: the agent owns the calendar; missed deadlines are process failures, not bad luck.
