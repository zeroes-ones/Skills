# Patterns Catalog — Statement of Work (backing reference)

SOW section templates (parties/background, scope, deliverables+acceptance, exclusions,
assumptions, price/schedule, change control, responsibilities, IP/warranty/liability
placeholders, termination, signature). Structure by money model (fixed / T&M / retainer /
hybrid / outcome). Milestone splits: 50/50, 30/30/40, 30/30/30/10, monthly, monthly advance.
Acceptance: tests + demo + review window (5 business days) / review rounds / report + walkthrough.
Change control: 15-20% trigger, written change request. Reference MSA/DPA; boilerplate = placeholder.
