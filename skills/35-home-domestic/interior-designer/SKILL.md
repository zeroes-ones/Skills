# Interior Designer (non-professional) — portability: apartment / house / studio

<!-- QUICK: 30s --> One-liner: Use a 60/30/10 color rule, three-layer lighting, and furniture scale templates to arrange functional, comfortable rooms on a budget while avoiding common proportion and circulation mistakes.

Quickstart (30s):
1) Measure: room length, width, ceiling height; note windows, doors, radiators.
2) Apply 60/30/10: pick dominant wall color, secondary upholstery, accent color.
3) Layer lighting: one ambient source, one task light per work area, one accent lamp per focal point.

<!-- STANDARD: 3min --> Ground Rules (mechanical triggers):
- Trigger A: "Path clearance" — keep 30–36" clear for primary circulation paths; 24–30" for secondary.
- Trigger B: "Furniture scale" — sofa depth 32–40"; coffee table height within 2" of sofa seat height; leave 12–18" between sofa and coffee table.
- Trigger C: "Light check" — any task area must have 300–500 lux at task plane; measure with lux meter app.

Decision Tree (4-5 levels):
```
Design decision
├─ Function first? -> Yes -> choose furniture by use (e.g., desk for 8-hr work = ergonomic chair + 120x60 cm desk)
│   └─ No -> Prioritize aesthetics -> pick pedigree piece then fit function around it
├─ Small room under 10x10 ft -> Use light palette, multi-functional furniture (daybed, nesting tables)
├─ Natural light low -> Increase ambient lumens and add warm accent lighting
└─ Budget constrained -> Prioritize investment: sofa and mattress; save on accessories
```

Core Workflow (STANDARD)
1. Measure & map: create 1:20 scaled plan or tape-out on floor.
2. Decide focal point: fireplace, window, TV, large art.
3. Choose main furniture by scale & function; anchor with rug sized to 60–75% of floor area under seating grouping.
4. Layer lighting and textiles; add 2–3 textures (wood, metal, textile) and 1 patterned element.

Core Workflow (DEEP)
- Color protocol: determine Munsell-adjacent hue or use Benjamin Moore/Behr swatch; test 2'x2' painted sample and view at AM/PM light before committing.
- Lighting protocol: calculate lumen budget: room area (sq ft) x target fc (footcandles 20–30 for living, 50–75 for kitchen) and pick fixtures with correct lumen output after dimmer derating.

<!-- DEEP: 10+min --> War stories, failure narratives, expert techniques:
- Failure: rug too small — moved forward and found visual fragmentation; fix: swap for 8'x10' rug to allow front legs on rug for seating unity.
- Technique: creating depth with paint — paint back wall 10–15% darker than side walls using same hue; pair with 2700K warm accent lights to create cozy depth.
- Contractor coordination: always measure twice, allow 10% contingency in budget for unexpected structural patching, get at least 3 bids, supply dimensioned drawings.
- Sustainable spec: use low-VOC paint (Green Seal certified), FSC-certified wood, OEKO-TEX fabrics, and specify GWP for insulation products when possible.

Error Decoder
| Symptom | Likely Cause | Fix |
|---|---:|---|
| Room feels cramped | Furniture scale too large or layout blocks flow | Remove one large piece, use scaled alternatives |
| Lighting too harsh | Wrong color temp or lack dimmer | Install dimmers, pick 2700–3000K for living spaces |
| Colors muddy | Undertone mismatch in samples | Swap to complementary undertone, test small area |
| Echo/poor acoustics | Hard surfaces, high ceilings | Add rugs, curtains, soft furniture, acoustic panels |
| Window treatments too long/short | Wrong mount point | Hang curtains 4-6" above trim for visual height |

Best Practices (opinionated)
1. Always start with scale — tape-out furniture footprint before buying.
2. Invest in one key seat (sofa or dining chairs) — spend 30–40% of room budget there.
3. Use warm white bulbs (2700–3000K) in living spaces; bright white (3500–4100K) for task areas.
4. Rug sizing: seating group rule — at minimum, front legs on rug; ideal: all legs on rug.
5. Window treatments: mount curtains close to ceiling, extend width 10–15 cm beyond frame each side.
6. Layer textures: combine one rustic wood, one woven textile, one metallic accent.
7. Art hanging: center of artwork at 57–60" from floor; groupings use 2–4" spacing between frames.
8. Traffic flow: maintain 90 cm (36") primary aisles; site furniture to allow natural walk paths.
9. Color: use 60/30/10 rule; for small rooms prioritize high-reflectance neutrals to increase perceived volume.
10. Contracts: always get scope, schedule, payment milestones, and signed change order policy.

Concrete Protocols / Recipes
Protocol: Seating Layout for Living Room (12'x16')
- Measurements: sofa 84" (213 cm) long, depth 36" (91 cm), coffee table 48x24".
- Steps: Tape a rectangle 12'x16'. Place sofa 18" from longest wall unless the focal point demands otherwise. Place coffee table 40–45 cm from sofa edge. Set two chairs at 90° angle with 60–90 cm clearance to allow circulation. Center rug so front legs of sofa and chairs are on rug and maintain 30–36" aisle to entry.

Protocol: Lighting Layer Calculation
- Steps: Calculate room area: width x length (e.g., 4m x 5m = 20m²). Target lux for living room: 150 lux (approx 14 fc). Required lumens = area (m²) x lux target x room coefficient (1.5) -> example: 20 x 150 x 1.5 = 4,500 lumens. Choose fixtures to sum to that figure: ambient fixture 2,500 lm + 2 task lamps at 1,000 lm each; include dimmers and 2700K bulbs.

Verification
- Walk test: perform 3 simulated activities (reading, watching TV, cleaning) and adjust light and layout until no task requires moving from its primary position.
- Scale confirmation: tape-out vs actual furniture: if average clearance < 20% predicted, iterate layout.
- User satisfaction: gather 3-day feedback from household on traffic flow and sightlines.

What Good Looks Like
- Rooms where primary activities can occur without moving furniture, light levels meet task needs, colors feel consistent under AM/PM light, and guests comment on comfort and cohesion.

Scale Depth

- Small household: whole-apartment design with consistent palette and lighting strategy.
- Medium: multi-room coordinated plan with contractor work for built-in elements.
- Enterprise: large residential projects require licensed architects/engineers (this guide stops here).

Anti-Hallucination
- All lumen, dimension, and clearance figures are explicit. For structural changes, consult licensed professionals. If a chosen material spec conflicts with local building code, default to contractor guidance and code references.
