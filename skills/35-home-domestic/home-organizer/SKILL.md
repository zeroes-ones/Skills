# Home Organizer — portability: apartment / house / moving truck

<!-- QUICK: 30s --> One-liner: Apply a zone + container + rhythm system to make every item have a home, reduce decision friction, and convert decluttering into a repeatable 20-minute daily practice.

Quickstart (30s):
1) Do a 10-minute flat-surface clear: 15-minute limit per surface; remove or sort everything into keep/donate/recycle.
2) Establish 3 zones: Entry, Kitchen, Home Office. Put one labeled container in each for "inbox".
3) Set maintenance: 5-min nightly reset; 30-min weekly reset Saturday morning.

<!-- STANDARD: 3min --> Ground Rules (mechanical triggers):
- Trigger A: "Entry unload" — when you enter, remove keys, mail, and bag into designated 3-item tray.
- Trigger B: "Inbox zero" — if paper stack > 10 items, run paper triage: archive, action (<=2 min), or recycle.
- Trigger C: "Donation bin" — if an item hasn't been used in 12 months and doesn't spark joy, move to donation bucket.

Decision Tree (4-5 levels):
```
Have item
├─ Is it used in last 12 mo? (Y) -> Keep
│   └─ No -> Does it spark joy or have legal value? -> Keep if legal; else donate
├─ Is it seasonal? -> Store in labeled container with clear inventory tag
├─ Fragile / Memorabilia -> Photograph and keep one physical item
└─ Duplicate -> Keep best-quality; sell/donate others
```

Core Workflow (STANDARD)
1. Zone mapping: map each room into 3–6 functional zones (e.g., kitchen: prep, storage, cleanup, kid-zone).
2. Container selection: choose only clear-stackable bins for storage; label with 1-line label.
3. One-in-one-out policy for consumables and clothing: when adding, remove one.

Core Workflow (DEEP)
- Shelf optimization: measure depth/height; use 40–50% free space rule for accessibility; keep daily items at 0.6–1.5m height.
- Closet system: use same-hanger method; color-code by category; fold shirts using KonMari 4-part fold; use slimline non-slip hangers.

<!-- DEEP: 10+min --> War stories, failure narratives, expert techniques:
- Failure: overbuying storage containers without measuring shelf depth; fix: measure shelves and purchase modular bins in multiples of shelf depth.
- Case: moving into 800 sq ft and losing entryway; solution: install 12"-deep wall-mounted cubby with 6 labeled slots, magnetic key strip, and 2 dedicated shoe slots.
- Technique: digital photo triage — adopt consistent filename convention YYYYMMDD_subject_location and store originals in cloud + local backup; cull yearly.
- Paper protocol failure: scanning 20-year receipts without indexing; fix: implement 3-tag system: tax, warranty, reference; keep 7-year retention for tax docs.

Best Practices (opinionated)
1. Adopt the 3-item rule at entry: keys, wallet, daily mail — everything else goes to staging box.
2. Use clear, stackable bins in metric multiples (e.g., 30x20x15 cm) to guarantee shelf compatibility.
3. Label with 18pt font and one-line description; include content and last audit date.
4. Horizontal surface rule: max 5 items. If exceed, decide immediately.
5. Digital folder structure: /YYYY/Category/Project — enforce filename: YYYYMMDD_subject_version.ext.
6. Paper: scan to PDF/A, run OCR, tag with 3 keywords: type, year, owner.
7. Closet hangers all facing same direction; rotate as-use pattern to identify unused items after 6 months.
8. Use a shared family calendar (Google Calendar) for chores and events; color-code by person.
9. Anchor heavy items low and close to studs; use toggle anchors only for light load containers.
10. Measure before buying organizers; return policies: keep receipts and test for 7 days.

Concrete Protocols / Recipes
Protocol: Entryway Rapid Reset (2 minutes)
- Tools: 9x6 tray, magnetic key strip, 2 cloth bins for shoes and outdoor gear.
- Steps: 1) Remove shoes into shoe bin; 2) Hang keys on strip; 3) Place incoming mail in "action" slot; 4) Empty pockets into small tray; 5) Quick sweep with door-mounted broom if needed.

Protocol: Paper Triage (10 minutes per mailbox)
- Tools: scanner (Fujitsu ScanSnap or smartphone app), 3 boxes labeled: Action (<=2 min), Archive, Recycle.
- Steps: 1) Open mail over the table; 2) Immediately discard known junk; 3) Action items: add to calendar or task app; 4) Archive receipts/records into scanner queue; 5) Recycle remaining.

Verification
- Conduct a 30-day audit: randomly check 10 labeled containers for correct content percentage (target 95%).
- Track time-to-find for 10 items: average < 45s.
- Weekly reset completion rate > 90% for 4 consecutive weeks.
